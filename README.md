# 비침습 입력을 이용한 청년층 대사 소견 유형 분석과 모델 비교

국민건강영양조사 2020–2024년 자료를 이용한 공동 연구의 **논문 작성 준비 저장소**입니다. **[my_model.ipynb](my_model.ipynb)가 메인 분석 노트북**입니다. 원래 분석 흐름에 공통 표본의 모델 비교 결과와 설명을 연결했으며, 로지스틱 회귀·트리·신경망 모델 중 직접 구현한 EPF도 비교 대상으로 포함했습니다.

## 논문 작성에 사용할 자료

| 자료 | 용도 | 상태 |
|---|---|---|

| [4쪽 논문 1차 원고](paper/manuscript_review.docx) / [본문 원본](paper/manuscript.md) | 익명 심사용 양식의 서론·방법·결과·논의·참고문헌 | 모델 비교 중심 초안, R 그림 3개 포함 |
| [연구 정의와 변수 사전](paper/01_study_definition.md) | 기간·대상자·15개 입력·5군 라벨·분할·가중치 | 모델 비교 기준 확인 완료 |
| [모델 비교 결과](paper/02_model_comparison.md) | 공통 4,508명에서 8조건의 성능 | 학습·평가 완료 |

| [논문 작성 순서와 공동저자 확인 항목](paper/03_writing_plan.md) | 서론·방법·결과·고찰 작성과 기존 분석의 연결 | 작성 준비 |

모델 비교는 20–39세 미인지 조건과 공복·검사·임신·조사설계 조건을 적용한 뒤, 저녁 동반 식사 문항을 사용하는 영양조사 참여자 **4,508명**에서 수행했습니다. 실제 예측 입력은 **15개**입니다. 원자료에서 선택한 **29개 열**에는 ID·검사값·진단 문항 등이 포함되므로 예측 변수 수와 다릅니다. 공동 연구 전체에 같은 대상자 정의를 적용할지는 요인 분석 담당자와 확인해야 합니다.

## 모델 비교의 현재 결과

| 모델 | macro AP | 95% PSU 구간 | macro AUROC | macro F1 |
|---|---:|---|---:|---:|
| 로지스틱 회귀 | 0.3443 | [0.3335, 0.3599] | 0.7282 | 0.2710 |
| Random Forest | 0.3439 | [0.3324, 0.3605] | 0.7268 | 0.2739 |
| XGBoost | 0.3493 | [0.3372, 0.3656] | 0.7334 | 0.2843 |
| LightGBM | 0.3515 | [0.3390, 0.3676] | 0.7321 | 0.2824 |
| MLP | 0.3488 | [0.3375, 0.3655] | 0.7320 | 0.2731 |
| 공동분포 선형 평균 모델 | 0.3444 | [0.3333, 0.3596] | 0.7372 | 0.2607 |
| 공동분포 MLP | 0.3485 | [0.3369, 0.3644] | 0.7357 | 0.2746 |
| EPF (공동분포) | 0.3515 | [0.3396, 0.3675] | 0.7354 | 0.2829 |

macro AP 범위는 0.3439–0.3515였고, 지표에 따라 모델 순위가 달랐습니다. 이 결과는 해당 표본과 평가 조건에서 관찰한 내부 비교이며, 특정 모델의 일반적 우수성·실제 임상 선별 효과·원인을 입증한 결과로 설명하지 않습니다. 직접 분류기와 공동분포 모델은 학습 목표와 연속 검사값 사용 여부가 다르며, 이 차이는 [방법 문서](paper/01_study_definition.md)에 명시했습니다.

## 공개 결과 재생성

```bash
python -m pip install -r paper/requirements-results.txt
python paper/render_results.py
```

또는 `paper/model_comparison.ipynb`를 저장소 폴더에서 실행하면 됩니다. 이 공개 패키지는 **집계 결과의 표·그림을 재생성**합니다. 학습을 다시 수행하거나 개인의 위험을 예측하는 실행기가 아닙니다. 원자료·개인별 예측·행 단위 설명값·학습 체크포인트는 포함하지 않았습니다. 재학습 코드는 현재 로컬 실험 폴더에 보존되어 있으며, 공개 재현 패키지의 범위는 공동저자 확인 항목입니다.

논문에 삽입한 그림은 R로 제작했습니다. 다음 명령은 `paper/results/metrics.csv`와 `class_ap.csv`의 집계값으로 같은 그림 3개를 재생성합니다. R의 기본 그래픽만 사용하며 추가 R 패키지는 필요 없습니다.

```bash
Rscript --vanilla paper/figures.R paper/results
```

1차 원고는 검증된 모델 비교 부분을 중심으로 작성했습니다. 기존 요인 분석의 표본·코딩을 맞춘 결과와 저자·윤리 관련 문구는 공동저자 확인 후 최종 원고에 연결합니다.

그림·그래프 3개와 표 2개를 참고문헌 뒤의 마지막 페이지로 모았습니다. 본문의 원래 위치에는 `(그림1)`, `(그림2)`, `(그림3)`, `(표1)`, `(표2)`만 표시했습니다.
