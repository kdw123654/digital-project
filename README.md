# 청년층 대사이상 선별: 기준선 노트북과 v28 모델 비교

국민건강영양조사(KNHANES) 2021–2024 자료를 사용한 연구 자료다. 이번 공개본은 **제공된 설명 노트북, 최신 v28 결과, 모델 구조와 학습 핵심 코드**만 추가했다. 원자료, 개인별 예측, 역할 인덱스, 대량 체크포인트, 실행 로그는 포함하지 않는다.

통합 노트북의 **앞부분 기준선과 후반부 v28은 별도의 실험**이다. 기준선은 4,680명·11개 입력·단일 이진 위험변수를 사용한다. v28은 4,068명의 고정된 5개 PSU fold, 114열 입력, 네 소견의 macro AP를 사용한다. 기준선의 AUC와 v28의 macro AP를 직접 비교하지 않는다. 공개용 편집과 후반부 실행 범위는 [노트북 설명](notebooks/PUBLICATION_NOTES.md)에 있다.

## v28 핵심 결과

10칸 × 설정 4개 × seed 5개 × fold 5개로 **1,000회 학습**했다. validation+calibration의 설계별 점수로 설정을 고른 뒤 test를 평가했다. 아래는 조사가중 OOF macro AP다.

| 설계 | Linear | MLP | EPF | P 제거 | 1단계 |
|---|---:|---:|---:|---:|---:|
| Binary | 0.36490 | 0.36510 | 0.36379 | 0.36378 | 0.36421 |
| Joint | 0.37538 | 0.37811 | **0.38140** | 0.38067 | 0.38061 |

- **H1은 4/5 통과했다.** Linear의 joint−binary 95% 구간은 `[-0.000136, +0.019695]`로 0을 포함한다.
- **H2는 P 제거·1단계 비교에서 통과했다.** 두 90% 구간은 사전 지정한 `(-0.005, +0.005)` 안에 있다. MLP·Linear와의 동등성은 확인되지 않았다.
- 평균 설계 효과는 **+0.014877**, PSU 95% 구간은 **[+0.005534, +0.023615]**다. joint 구조 사이의 관측 AP 범위는 **0.006020**이며 이는 신뢰구간이 없는 기술 통계다.

따라서 **사전 지정한 결합 기준은 미충족**이다. 설계 간 차이에는 연속 타깃 정보·손실·앵커·출력 경로가 함께 포함된다. 출력만의 인과 효과, 정확한 0 기여, 보편적인 구조 무관성을 입증한 것은 아니다. 재사용 코호트의 탐색 비교이며 PSU 구간은 고정 OOF 예측에 조건부다.

## 실행 범위

```bash
python -m pip install -r v28/requirements.txt
python -m models.clinical_v28.synthetic_demo
python -m pytest -q test_clinical_v28.py
```

모델 예제는 **합성 114열 입력**으로 구조·출력 계약을 확인한다. 실제 환자 예측이나 공개된 학습 가중치 실행 예제가 아니다. 모델 패키지에는 입력 배열과 fit 통계를 받는 학습 핵심 API가 있으며, 원자료 전처리·기존 역할 분할·fit 앵커·PSU 재표집 전체 파이프라인은 포함하지 않는다.

`v28/REPORT.ipynb`는 같은 폴더의 `PUBLIC_REPORT.json`만 읽는 원 집계 보고서다. 통합 `my_model_정리.ipynb`의 16–23절은 집계값을 내장하여 원자료 없이 설명과 새 표·그림을 읽을 수 있다. 후반부 그림만 다시 보려면 21절의 집계 코드 셀부터 실행한다. `Run All`은 앞부분의 원자료 분석·학습도 실행하므로, 앞부분 재실행에는 별도로 확보한 SAS 원자료와 해당 의존성이 필요하다. 이번 확장에서는 초기 학습이나 v28 모델 재학습을 하지 않았다.
