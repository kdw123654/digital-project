# 논문 작성 순서와 공동저자 확인 항목

제안 제목은 **비침습 정보를 이용한 청년층 대사 소견 유형 분석과 분류 모델 비교**다. 연구의 중심은 유형별 관련 정보와 모델 비교이며, EPF의 새로운 구조나 우수성을 주된 기여로 내세우지 않는다. EPF는 직접 구현해 비교에 포함한 신경망 중 하나로 소개한다.

메인 분석 자료는 [my_model.ipynb](../my_model.ipynb)다. 기존 분석 1–5절에 공통 표본 모델 비교 6절을 연결했고, 별도 `model_comparison.ipynb`는 집계 결과 재생성을 위한 보조 자료로 둔다. 모델 비교 중심의 [4쪽 1차 원고](manuscript_review.docx)와 [본문 원본](manuscript.md)을 작성했으며, 원래 요인 결과를 확정 결과로 합친 최종 공동연구 논문은 아직 아니다. 출판용 저자 정보와 요인 분석 기준을 확인하면 다음 개정에 연결한다.

## 공동저자와 맞출 항목

- [ ] 논문 전체 대상자를 미인지·12시간 공복·영양 참여 조건의 4,508명으로 통일할지, 요인 분석과 모델 비교를 서로 다른 분석 집단으로 명시할지 결정한다. 다른 집단의 수치를 합쳐 하나의 결과처럼 쓰지 않는다.
- [ ] 동료의 `weight_gain`은 BO1_1=3, `solo_dinner`는 L_DN_TO=2 방향이며, 비해당과 모름을 별도 처리하는지 확인한다. 초기 노트북의 코드와 다르면 요인 분석 담당자가 결과를 재확인한다.
- [ ] 검사값 결측을 정상으로 코딩하지 않고, 전처리와 컷오프 선택에 평가 자료를 쓰지 않는지 확인한다.
- [ ] 5군 지질 단독·복합 정의를 동일하게 사용한다. 6군 및 이진 결과는 별도 연구 또는 보조 결과로 표시한다.
- [ ] 가중치·PSU 분할·지표 척도가 다른 기존 점수를 새 비교표에 넣지 않는다. 이진 ROC-AUC와 5군 macro AP를 직접 대조하지 않는다.
- [ ] 요인 분석은 관련성·모델 기여로 설명한다. 단순 중요도 상위나 공통 변수를 제외한 top3만으로 특이성·원인·매개효과를 확정하지 않는다.
- [ ] LightGBM gain/split 중요도와 RF의 MDI를 구분하고, SHAP의 확률·logit 척도를 명시한다. 오즈비는 위험비나 인과효과로 바꾸어 설명하지 않으며, 회귀의 신뢰구간 계산이 사용한 규제·가중치·조사설계와 맞는지 확인한다.
- [ ] 1인가구를 실제 자취로 동일시하지 않는다. 가구·성별 분석의 표본 지원과 조사설계를 확인한다.
- [ ] 독립 외부 검증, 실제 임상 선별 효과, 검사비 절감, 즉시 상용화를 이번 데이터 결과로 주장하지 않는다.
- [ ] 저자 순서·역할, 자료 활용 및 윤리 관련 문구, 투고 형식, 최종 참고문헌은 공동저자가 확인한다. 확인되지 않은 승인 번호를 넣지 않는다.
- [ ] 공개 재학습 코드의 범위를 정한다. 현재 공개 패키지는 집계 표·그림 재생성까지 지원하며, 로컬 학습 코드·체크포인트는 공개하지 않았다.

## 참고문헌 준비

자료 정의는 [KDCA 이용지침서](https://knhanes.kdca.go.kr/knhanes/dataAnlsGd/utztnGd.do), 검사 소견 절단값은 [Grundy 등 2005 AHA/NHLBI 성명](https://doi.org/10.1161/CIRCULATIONAHA.105.169404)을 확인해 인용한다. SHAP을 사용하는 요인 분석 절에서는 [Lundberg와 Lee 2017](https://proceedings.neurips.cc/paper_files/paper/2017/hash/8a20a8621978632d76c43dfd28b67767-Abstract.html)을 방법 근거로 사용하며, 설명값을 인과효과로 바꾸어 읽지 않는다. 전처리·평가 역할은 [scikit-learn의 누수 방지 지침](https://scikit-learn.org/stable/common_pitfalls.html#data-leakage)과 구현을 대조한다. 이 링크들은 확인한 방법·기준의 출발점이며 서론의 유병률·정책 수치를 대신하지 않는다.
