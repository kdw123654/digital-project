# 수정 원고와 공동저자 확인 항목

교수님 피드백에 따라 EPF 중심 제목·구조 그림·5회 연도 제외 검증·EPF 자체 SHAP·검사값 학습 정답 설명을 반영했다. 실제 수치에 근거해 우수성 미확인과 단독군의 최대확률 결정 한계를 적었다. 그림과 표는 본문 뒤에 모았다.

심사용은 저자를 제외하고 출판용은 사용자가 제공한 수정본의 성명·소속·이메일을 옮겼다. 문서마다5쪽이며 본문/참고문헌3쪽과 그림·표2쪽이다. 제공 양식의 A4/여백/2단을 유지했다. 제출 페이지 제한에 맞춘 최종 편집과 저자 표기는 공동저자 확인이 필요하다.

동료의 이전 요인 분석과는 코호트/코딩/가중치가 달라 현재 원고에 같은 표본의 결과로 합치지 않았다. 요인 분석을 연결하려면 같은4,508명 정의로 재검증하거나 별도 분석 집단으로 표시한다. 자료 이용·윤리/IRB 문구, 기관/저자 표기, 투고처 제한을 확인한 뒤 제출본을 정한다. 인과효과·외부검증·임상 우수성이나 모델 최초 제안은 현재 결과에 덧붙이지 않는다.
