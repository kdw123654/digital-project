# 비침습 입력을 이용한 대사 소견 분류 모델 비교

2020–2024년 국민건강영양조사에서 비침습 입력을 이용한 대사 소견 유형 분류를 수행하고, 여러 모델의 예측 성능을 비교했다. 로지스틱 회귀·Random Forest·XGBoost·LightGBM·MLP와 공동분포를 이용하는 모델들을 같은 조건에서 평가했다. 직접 구현한 신경망 EPF도 비교 대상 중 하나로 포함했다.

분석 대상은 20–39세 미인지 코호트 중 영양조사 참여자 4,508명이다. 실제 비침습 입력은 15개이며, 라벨은 정상·혈압 단독·혈당 단독·지질 단독·복합의 배타적 5군이다.

29개는 원자료 선택 열 수이며 검사값·ID·진단 문항은 예측 입력으로 쓰지 않았다. 혼밥/체중 증가 코드를 수정하고 전처리는 fit에서만 적합했다.

| 모델 | macro AP | 95% 구간 | macro AUROC | macro F1 |
|---|---:|---|---:|---:|
| LR | 0.3443 | [0.3335, 0.3599] | 0.7282 | 0.2710 |
| RF | 0.3439 | [0.3324, 0.3605] | 0.7268 | 0.2739 |
| XGB | 0.3493 | [0.3372, 0.3656] | 0.7334 | 0.2843 |
| LGBM | 0.3515 | [0.3390, 0.3676] | 0.7321 | 0.2824 |
| MLP | 0.3488 | [0.3375, 0.3655] | 0.7320 | 0.2731 |
| jLinear | 0.3444 | [0.3333, 0.3596] | 0.7372 | 0.2607 |
| jMLP | 0.3485 | [0.3369, 0.3644] | 0.7357 | 0.2746 |
| jEPF | 0.3515 | [0.3396, 0.3675] | 0.7354 | 0.2829 |

모델별 macro AP는 0.3439–0.3515였다. LightGBM과 EPF의 점추정은 소수점 네 자리에서 같았으며, 지표에 따라 모델 순위가 달라졌다. 이 표는 해당 표본과 평가 조건에서 관찰한 성능을 제시한다.

표에서 `j`는 공동분포 출력을 뜻한다. 공동분포를 이용하는 선형 모델·MLP·EPF는 연속 검사값을 추가 학습 정보로 사용한 뒤 같은 5군 확률을 계산한다. 직접 분류기와의 차이에는 출력 설계와 학습 정보의 차이도 포함된다. EPF는 본 연구에서 직접 구현해 비교에 포함한 신경망이며, 그 자체의 우수성을 연구의 전제로 두지 않았다.

실험 단계에서 사전 지정했던 EPF−공동분포 MLP 대조는 +0.0030, 95% 구간 [-0.0024, +0.0088]이었다. 원래 분석 기록과 수치는 유지했으며, 이 문서에서는 여러 모델 비교 결과 중 하나로 설명한다. 구조의 추가 이득은 확인되지 않았다.

튜닝은 모든 모델당 8설정·seed42, 확률적 최종 모델은 seed42–44 평균이다. LR은 결정론적 한 모델이다. 동일 PSU 분할·동일 평가 대상·조사 가중치를 사용했다.

공개 노트북의 원래 점수와 직접 비교할 수 없다: 라벨/특징 코드는 같게 정리했으나 미인지·공복·임신·가중치·PSU 분할을 엄격히 적용했다.

기존에 관찰한 KNHANES를 재사용한 내부 비교다. 구간은 고정 예측에 대한 표본 불확실성이고 재학습을 포함하지 않는다. 원인·특이요인·임상 선별 효용은 평가하지 않았다.


집계 원문은 [comparison_summary.json](results/comparison_summary.json), 실행 표·그림은 [model_comparison.ipynb](model_comparison.ipynb)에 있다. 이번 공개 노트북은 집계 재생성용이며 새 학습을 수행하지 않는다.
