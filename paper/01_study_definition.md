# 연구 정의와 변수 사전

이 문서는 논문에 모델 비교 결과를 사용할 때 적용할 기준을 고정한다. 요인 분석의 대상자·가중치·라벨이 다르면 그 결과를 같은 표본의 결과처럼 합치지 않고, 공동저자 확인 후 별도 분석 또는 재분석으로 정리한다.

## 자료와 대상자

자료는 질병관리청 국민건강영양조사 2020–2024년 반복 횡단면 원시자료다. 조사연도 간 비교는 같은 사람의 추적이나 미래 발병 예측이 아니다. 출처는 [국민건강영양조사](https://knhanes.kdca.go.kr/knhanes/main.do), 코드와 측정 주의사항은 [제8·9기 원시자료 이용지침서](https://knhanes.kdca.go.kr/knhanes/dataAnlsGd/utztnGd.do)를 따른다.

모델 비교 대상자 선정 순서는 다음과 같다. 19–39세에서 고혈압·당뇨·이상지질혈증 진단 상태 확인 및 기존 진단 없음, 관련 복약 상태 확인 및 복약 없음, 명시적 비임신 상태, 12시간 이상 공복, 다섯 검사값 완전 관측·양수, SBP>DBP, 유효 설계정보 조건을 적용했다. 그 결과 5,229명이 남았다. 이 중 20–39세 5,055명에 제한하고, 영양조사 결합 가중치 `wt_tot>0`인 참여자 4,508명을 공통 평가 대상으로 삼았다. 이 수는 전체 청년 응답자 수가 아니라 해당 조건을 충족한 수다.

남성은 `HE_prg=8`, 여성은 `HE_prg=0`을 확인했다. 진단·복약·임신 및 정답 검사의 모름을 정상으로 코딩하지 않았다. 가중치는 `wt_tot`을 사용했고 학습 역할에서 평균 1로 정규화했다. 같은 5년의 가중 평균 지표에는 모든 가중치를 1/5로 나누는 상수가 상쇄된다. 영양조사 비참여를 식사 변수의 0으로 대체하지 않았다.

| 연도 | 모델 비교 대상자 |
|---|---:|
| 2020 | 851 |
| 2021 | 792 |
| 2022 | 926 |
| 2023 | 965 |
| 2024 | 974 |
| 합계 | 4,508 |

## 15개 비침습 예측 입력

| 입력 | 원자료 또는 계산 | 처리와 의미 |
|---|---|---|
| 연령 | `age` | 20–39세 |
| 성별 | `sex` | 1 남성, 2 여성 |
| 소득수준 | `incm` | 1–4 범주, 모름은 결측 |
| 교육수준 | `edu` | 1–4 범주, 모름은 결측 |
| BMI | `HE_BMI` | 양수 신체계측 |
| 허리둘레 | `HE_wc` | 양수, cm |
| 허리둘레/키 비율 | `HE_wc/HE_ht` | 키가 양수일 때 계산 |
| 현재흡연 | `sm_presnt` | 0/1 |
| 월간음주 | `dr_month` | 0/1 |
| 유산소 활동 | `pa_aerobic` | 0/1 |
| 1인가구 | `cfam==1` | 2–6명은 0, 모름은 결측. 실제 자취와 동일하지 않음 |
| 좌식시간 | `BE8_1` | 0–24시간 범위; 이 비교에서는 시간 열 사용 |
| 저녁 혼밥 관련 | `L_DN_TO` | 1=동반 식사 있음→0, 2=없음→1, 3=저녁 빈도 비해당→별도 수준 2 |
| 1년 체중 증가 | `BO1_1` | 3=증가→1, 1=변화 없음/2=감소→0; 모름은 결측 |
| 취침 전 칫솔질 미실시 | `BM1_8` | 0=미실시→1, 1=실시→0; 모름은 결측 |

15개 입력은 동일한 인코더를 통해 45열로 변환했다. 수치형은 학습 역할의 가중 평균·표준편차로 표준화하고, 결측은 표준화 값 0과 결측 지시자로 표현했다. 범주형은 사전 정의 수준과 결측 수준을 인코딩했다. 평가 자료의 평균·최빈값으로 전처리를 적합하지 않았다. ID·설계변수·검사값·진단 및 복약 문항은 예측 입력이 아니다.

## 검사 소견과 배타적 5군

| 소견 flag | 양성 기준 |
|---|---|
| 혈당 상승 | 공복혈당≥100 mg/dL |
| 혈압 상승 | SBP≥130 mmHg 또는 DBP≥85 mmHg |
| TG 상승 | TG≥150 mg/dL |
| 저HDL | 남성<40, 여성<50 mg/dL |

이 절단값은 대사증후군 구성요소를 참고한 **검사 소견**이며 질환 확진이나 대사증후군 진단 자체가 아니다. [AHA의 기준 설명](https://www.heart.org/en/health-topics/metabolic-syndrome/symptoms-and-diagnosis-of-metabolic-syndrome)에서 같은 혈당·혈압·TG·HDL 기준을 확인했다. 학술 인용은 혈당 100 기준의 수정판인 [AHA/NHLBI 2005 성명](https://doi.org/10.1161/CIRCULATIONAHA.105.169404) 본문을 확인해 연결하고, 원래 ATP III 2001의 혈당 절단값과 혼동하지 않는다.

원래 네 flag의 16조합을 보존하고, 지질 영역을 `TG 상승 OR 저HDL`로 정의해 혈당·혈압·지질의 세 영역 수를 센다.

| 5군 | 정의 | 비가중 n |
|---|---|---:|
| 정상 | 네 소견 모두 음성 | 2,796 |
| 혈압 단독 | 혈압만 양성 | 183 |
| 혈당 단독 | 혈당만 양성 | 233 |
| 지질 단독 | TG/저HDL 중 하나 이상 양성, 혈당·혈압 음성 | 813 |
| 복합 | 혈당·혈압·지질의 세 영역 중 두 영역 이상 양성 | 483 |

TG와 저HDL만 함께 이상인 경우는 이 5군 정의에서 지질 단독이다. 기존 6군 연구의 복합군과 다른 정의다. 정상은 이 네 소견이 없다는 의미이며 모든 건강 문제가 없다는 의미는 아니다.

## 모델 비교 방법

연도별 균형을 고려한 PSU 5개 outer fold에서 OOF 예측을 만들었다. PSU와 가구는 `(연도, PSU)` 및 `(연도, PSU, 가구ID)` 키로 묶고 역할 간 겹침을 검사했다. outer 학습 부분을 PSU 기준 80% fit/20% validation으로 다시 나눴다. 모든 모델에서 같은 사람·입력·역할·가중치를 사용했다.

모델당 후보 8개를 seed42로 평가하고 validation의 조사 가중 5군 macro AP로 설정을 선택했다. LR은 결정론적 한 모델, 나머지는 선택된 설정의 seed42–44 확률 평균이다. 직접 MLP는 교차엔트로피, 공동분포 모델은 Gaussian NLL로 학습·중단하며, 후보 선택 지표는 macro AP로 통일했다. 모델군별 손실은 같지 않다는 점도 기술한다.

직접 LR·RF·XGBoost·LightGBM·MLP는 5군을 분류한다. 공동분포 선형 평균 모델·MLP·EPF는 log glucose, log DBP, log(SBP−DBP), log TG, log HDL의 대각+rank-one 조건부 Gaussian을 학습하고 같은 5군 확률로 집계한다. Ridge 앵커와 로그 표준화는 fit 역할에서 구하고 앵커 설정은 validation에서 선택했다. 연속 검사값은 공동분포 계열의 추가 학습 정보이므로 직접 분류기와의 차이를 구조만의 효과로 부르지 않는다.

EPF는 기존 구현의 12개 복소 상태·4회 내부 반복·사건 및 가소성 상태를 사용하는 신경망으로 비교에 포함했다. 같은 joint 출력의 MLP·선형 평균 모델도 함께 두었다. 모델이 실제 생리 기전을 표현한다고 해석하지 않는다.

주 지표는 5군 one-vs-rest 조사 가중 AP의 평균이다. AUROC, macro F1, balanced accuracy, NLL, Brier는 보조 지표다. 95% 구간은 (연도, 층) 안에서 전체 조사 PSU를 Rao-Wu 재표집한 2,000회로 구했다. 고정된 모델 예측의 조건부 구간이며 재학습 불확실성은 포함하지 않는다. 관찰된 점수 순위·구간 겹침만으로 모델의 일반적 우수성 또는 동등성을 선언하지 않는다.

## 측정과 선택의 한계

이번 5개년 비교는 원자료의 측정값에 같은 절단값을 적용했다. 2021년 혈압계와 2022년 검사기관·분석법 등의 변경에 대한 별도 전환식 민감도 분석을 이 비교에 추가하지 않았다. 모든 조건은 같은 정답을 사용하지만, 연도별 측정 차이를 생물학적 변화로 해석하지 않는다. 진단·공복·검사 완전성·영양 참여 조건으로 선별된 표본이라는 점도 일반화 범위를 제한한다.
