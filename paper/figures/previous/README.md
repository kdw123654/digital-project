# 사용자가 제공한 원고의 원래 그림

교수님은 기존 그림 전체의 삭제를 요청하지 않았다. 연구 흐름·전체 성능·혼동행렬·SHAP의 기능을 유지하면서 최신 연도 제외 평가와 EPF 기준 설명으로 갱신했다. Binary–Joint 출력 설계 비교의 원본은 메인 노트북 참고 부록에서 확인할 수 있다.

원본 그림4개를 사용자의 수정DOCX에서 바이트 그대로 추출했다. 대상자6,588명·70:30 분할 및 과거 네소견AP와 현재4,508명·5군AP는 비교 기준이 다르다. 원본의SOTA/유의성/행동원인 주장을 현재 연구 결과로 옮기지 않는다. 최신 논문 본문 그림은 상위폴더의figure1–figure5이다.
