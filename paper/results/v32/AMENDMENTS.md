# v32 완료 및 공개 패키지 기록

원래 PROTOCOL과 REPORT의 수치·선택 규칙·결과 해시는 보존하였다. 정식 사전등록이나 독립 외부검증으로 부르지 않는다.

1. 다섯 군 SHAP에서 배타적인 아형 사이 확률 이동을 확인한 뒤, 네 원래 소견의 확률 SHAP을 추가했다. 결과를 본 뒤의 해석 점검이다. 주 지표·비교군·모델 선택과 시험 예측은 바꾸지 않았다.
2. 공개 패키지 준비 중 v32 prepare에 최초 실행의 v31 코호트 생성 연결을 추가했다. 호출은 자료 준비만 수행하며 v31 학습은 실행하지 않는다.
3. SHAP의 경로 계산 함수를 v30_explain에서 독립 모듈로 옮겨 구버전 연구 의존성을 제거했다. 동일 입력에서 모든 반환값의 완전 일치를 테스트했다. 완료된 설명값을 다시 추정하지 않았다.
4. 실행기는 현재 Python 인터프리터를 사용하도록 경로만 바꿨다. 훈련 조건은 같다. 원본 훈련 당시의 코드 해시와 공개 코드 해시는 COMPLETION과 공개 SOURCE_MANIFEST에 구분한다.
5. REPORT의 축약 bootstrap 항목에 빠진 설계 단위 수는 COMPLETION의 bootstrap_design에 보완했다. 같은 표본과 원래 코드를 읽은 메타데이터 보완이며 신뢰구간을 다시 계산하지 않았다.

신경망 seed 변동은 별도 값으로 보고했고, 고정 예측 PSU 구간에 재학습 변동이나 모델 탐색 전체의 불확실성이 들어간다고 주장하지 않는다.
