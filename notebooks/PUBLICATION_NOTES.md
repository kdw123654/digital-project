# 초기 기준선 노트북 공개 메모

`my_model_정리.ipynb`는 사용자 제공 노트북의 공개용 복사본이다. 원본 파일은 변경하지 않았다. 공개 준비에서는 노트북, 원자료 읽기, 학습, 지표 계산을 실행하지 않았다. 남은 집계표·차트는 원본에 저장된 결과다.

## 파일 무결성

- 제공 원본 SHA-256: `40f5753553b9ca8f8e94517bff13763dcc70f2cc77c4d7fe5f1d4af7b5eb3f6e`
- 공개 노트북 SHA-256: `6a72bcbb4585cce367754a33c13307a13bd8e688ae7e3aab379a9222411de159`
- 공개 파일은 UTF-8·LF로 저장했다. 위 공개 해시는 Git에 저장될 LF 바이트 기준이다.

## 공개용 변경

셀 번호는 **0부터 시작**한다.

- **0**: 공개용 수정 및 미재실행 안내, 원문 추가 검토 수치의 출처, 초기 기준선과 v28 범위 차이를 명시했다.
- **3**: 원자료 파일 위치를 저장소의 `data/raw/`로 안내했다.
- **4, 6**: 컴퓨터에 고정된 경로를 `data/raw/hnYY_all.sas7bdat` 상대 위치로 바꾸었다. 저장된 개인별 5행 미리보기 출력(`text/html`, `text/plain`)을 제거하고, 해당 `head()` 코드를 크기·열 이름 출력으로 바꾸었다. 기존 집계 stdout은 유지했고 새 실행 결과를 만들지 않았다.
- **17**: 로컬 환경 경로가 포함된 stderr 출력만 제거했다. ROC 그림과 모델 성능표는 유지했다.
- **18**: 제거한 환경 출력에 관한 설명을 공개본 기준으로 갱신했다.
- 코드 또는 출력이 변경된 **4, 6, 17**의 `execution_count`는 비웠다. 나머지 셀의 코드·집계 출력·차트는 보존했다. 첨부 파일과 개인 정보를 담은 셀 메타데이터는 없었다.

## 분석 범위와 결과 해석

초기 기준선은 치료자 제외 후 5,204명에서 입력 결측을 제거한 **4,680명**, 입력 **11개**, **단일 이진 Target**(대사이상 소견 4개 중 1개 이상)을 사용한다. 70/30 분할의 학습 3,276명·시험 1,404명에서 원본 저장 결과의 로지스틱 ROC-AUC는 0.804777, 평균 정밀도(AP)는 0.695022다. 이것은 현재 v28의 결과가 아니다.

[v28 실험](../v28/REPORT.md)은 **4,068명**, 인코딩된 입력 **114차원**, 4개 위험 지표와 16개 조합 상태를 다루는 별도 5-fold 설계 비교다. 두 분석의 표본·입력·목표·평가 방식이 달라 성능 수치를 직접 비교할 수 없다.

원문의 검사값 결측 처리, 진단/치료 구분, 시험 데이터로 임계값 선택, 하위집단 학습 자료 재평가, 오즈비 추정에 관한 한계 설명을 유지했다. 원문에 `정리자 확인`으로 적힌 추가 수치와 SPSS 재현 주장은 이번 공개 준비에서 독립적으로 재검증하지 않았다. 임상 성능을 새로 검증한 공개본이 아니다.

## 재실행에 필요한 파일과 패키지

원자료는 저장소에 포함하지 않는다. `data/raw/`에 `hn21_all.sas7bdat`, `hn22_all.sas7bdat`, `hn23_all.sas7bdat`, `hn24_all.sas7bdat` 네 파일을 별도로 준비해야 한다. 노트북의 작업 디렉터리는 저장소 루트 또는 `notebooks/`를 사용한다. 이 노트북은 SAS 파일을 읽으며 v28의 SPSS 자료 경로와 별개다. 원래 수집 반복문은 없는 연도 파일을 건너뛰므로 네 파일이 모두 있어야 기록된 4개년 분석 범위를 유지한다.

초기 기준선 코드의 외부 패키지: `numpy`, `pandas`, `pyreadstat`, `scikit-learn`(`sklearn`), `scipy`, `matplotlib`, `seaborn`, `xgboost`, `lightgbm`. 노트북 실행에는 Jupyter 및 Python 커널도 필요하다. 표준 라이브러리는 `os`, `warnings`, `pathlib`이다. 원본 메타데이터의 Python 버전은 3.13.5이며, 원본 실행 패키지 버전 전체는 기록돼 있지 않다. 이 목록은 초기 기준선의 의존성 안내로, v28의 학습 의존성 목록과 구분한다.

이 초기 노트북을 실행하면 기준선 및 하위집단 모델을 새로 학습한다. v28의 1,000개 학습 단위를 수행하는 코드도, v28 공개 집계 JSON을 읽는 보고서 코드도 아니다. v28의 `REPORT.ipynb`는 별도 `PUBLIC_REPORT.json`을 읽는 집계 보고서다.
