# v28 고정 실험 조건

- 대상: KNHANES 2021–2024, 만 19–39세 4,068명. 기존에 고정한 PSU 분리 5개 fold와 fit/validation/calibration/threshold/test 역할을 사용했다.
- 입력: 동일한 비침습 원시 38개 변수에서 fit 전용 전처리로 만든 114열.
- 설계: binary(네 flag BCE·로지스틱 앵커)와 joint(검사값 다섯 개의 가우시안 공동분포 NLL·Ridge 앵커).
- 구조: Linear, MLP, EPF, EPF_noP, EPF_step1. 각 칸에 lr `{0.0003, 0.001}` × weight decay `{0, 0.001}`, seed 42–46을 동일하게 적용했다.
- 최대 300 epoch, patience 30, validation BCE 또는 NLL로 checkpoint 선택. 각 설정의 validation+calibration 가중 점수를 seed 평균하여 최종 설정을 선택했다. test를 열기 전에 50개 설정을 동결했다.
- 최종 예측: 선택한 다섯 seed의 p4와 p16을 각각 평균한다. binary의 각 seed는 독립 Bernoulli 곱이지만, 이 분포들의 혼합은 의존성을 가질 수 있다.

## 사전 지정 판정

H1은 다섯 구조 각각에서 `joint − binary` macro AP의 PSU 95% 구간 하한이 0보다 큰지 본다. 다섯 개 모두 통과해야 전체 H1 조건을 충족한다.

H2는 joint EPF와 noP·step1·MLP·Linear 각각의 차이에 대해 PSU 90% 구간이 `(-0.005, +0.005)` 안에 있는지 본다. 이는 해당 코호트의 macro AP에 대한 동등성 한계이며 정확한 0 효과나 모든 성능 지표의 동등성을 뜻하지 않는다.

PSU 재표집은 2,000회, 고정 난수 seed 20260930이다. 16상태 categorical NLL, 소견별 AP, fold별 차이, 평균 설계 효과도 보고한다. NLL은 주변확률의 정확도·보정에도 영향을 받으므로 의존성 모델링만의 효과를 분리하지 않는다.

## 구현과 해석의 범위

원본 v28의 모델·학습·선택·평가 함수는 수정하지 않고 외부 실행기로 해시·동결·로그를 추가했다. 중단 시 완료된 683개를 보존하고, 미완료 2개를 같은 조건으로 재시작해 나머지 317개를 완료했다. 학습 실패와 자동 재시도는 0건이며 중단·수동 재개는 별도 기록했다.

noP에는 대체 capacity 특성이 남고 step1에서는 P도 0이 된다. joint Linear의 평균 경로는 선형이지만 공분산에는 적응형 head가 있다. 두 학습 설계 사이에는 타깃·손실·앵커·EPF readout 경로 차이도 있다. 동일한 설정 수가 동일한 매개변수 수나 완전히 분리된 단일 요인 개입을 뜻하지 않는다.

이 저장소는 결과 집계 재실행과 모델·학습 핵심 코드 점검을 위한 공개본이다. 원자료, 대상자별 예측, 역할 인덱스, 앵커 자산, 체크포인트를 제공하지 않으므로 새 환경에서 원래 코호트의 1,000회 전체 실험을 그대로 재생하는 패키지는 아니다. 모델 API와 준비해야 할 입력은 [모델 설명](../models/clinical_v28/README.md)을 따른다.
